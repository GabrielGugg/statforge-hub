# Fallout TTRPG 2.2 (EN)

Fallout TTRPG 2.1 (Arcane Arcade) in its original English, with the house rules of Fallout 2.2: contradictions settled, broken rules fixed and a few prices and starting kits corrected. Book texts keep their page "(p. N)"; anything changed says "changed in 2.2". By GabrielGugg.

| File | Type |
| --- | --- |
| `fallout-2.2-en.json` | system |

## Version

This package keeps its own version. Its 0.1.0 matched the Portuguese package `fallout-2.2-pt` 1.14.0; changes made to the Portuguese package after that are not included yet.
