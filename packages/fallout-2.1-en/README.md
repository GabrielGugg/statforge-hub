# Fallout TTRPG 2.1 (EN)

Fallout TTRPG 2.1 (Arcane Arcade) as written in the original English book, without house rules. Broken rules are kept: where they affect the sheet, the player picks an option (explained on the sheet) or the field is manual. Every rules text ends with its book page "(p. N)". By GabrielGugg.

## Gugg's Revision

GabrielGugg's house rules, formerly the "Fallout TTRPG 2.2" package, are now an extension of 2.1 (EN). With it active, the sheet is the same as the old 2.2. Among other things, it:

- uses the higher modifier for two-attribute skills (Breach, Intimidation, Medicine);
- takes only 1 off every skill for negative Luck (no rule choice);
- works out Combat Sequence from Perception and rounds the Healing Rate;
- keeps Gen 2 Synths from using Stimpaks and gives Handy three tools;
- adds the Off-Balance condition and a rule for power armor upgrade ranks, and fixes prices and texts (Hazmat Suit, T-45, Caltrops, Pit Fighter, Vault Dweller, chem addiction and more).

To use it, install the system and the extension and turn the extension on in the sheet. It can be combined with other 2.1 (EN) extensions, such as another fan's revision: the app applies extensions in the order of the Packages screen, and when two touch the same thing the lower one wins (the app warns you). Gugg's Revision replaces the whole character creation steps and layout, so if another extension also changes those, the lower one wins.

## Version

This package keeps its own version. Its 0.1.0 matched the Portuguese package `fallout-2.2-pt` 1.14.0 (now `fallout-2.1-pt` with the `fallout-2.1-gugg-pt` extension); changes made to the Portuguese packages after that are not included yet.
